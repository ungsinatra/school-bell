# Школьные звонки

Десктопное приложение для автоматического воспроизведения школьных звонков по расписанию.  
Стек: **Electron** + **React** + **TypeScript** + **Vite**.

---

## Требования

- Node.js 20+
- npm

---

## Установка

```bash
npm install
```

Создайте файл `.env` в корне проекта (если его нет):

```env
PORT=5173
```

---

## Запуск в режиме разработки

| Команда | Описание |
|---------|----------|
| `npm run start` | Запускает Vite (React) и Electron одновременно |
| `npm run start:react` | Только фронтенд на `http://localhost:5173` |
| `npm run start:electron` | Только Electron (нужен уже запущенный Vite) |

Рекомендуемый способ:

```bash
npm run start
```

В dev-режиме Electron подключается к Vite dev server, DevTools открываются автоматически.

## Сборка и деплой

Сначала собирается фронтенд (`tsc` + `vite build`), затем упаковывается Electron-приложение.  
Готовые артефакты попадают в папку `release/`.

| Команда | Платформа | Результат |
|---------|-----------|-----------|
| `npm run build` | — | Только сборка фронтенда в `dist/` |
| `npm run build:win` | Windows x64 | NSIS-инсталлятор |
| `npm run build:win:arm` | Windows ARM64 | NSIS-инсталлятор |
| `npm run build:mac` | macOS | `.dmg` |
| `npm run build:linux` | Linux | `.AppImage` |
| `npm run lint` | — | Проверка ESLint |
| `npm run preview` | — | Превью production-сборки Vite |

Пример сборки под Windows:

```bash
npm run build:win
```

## Функциональность

- **Планировщик звонков** — автоматически воспроизводит мелодии в заданное время по расписанию смен
- **Несколько смен** — независимые расписания (1-я смена, 2-я смена и т.д.)
- **Уроки и перемены** — разные типы записей с отдельными мелодиями
- **Предупреждение об окончании** — дополнительный звонок за N секунд до конца перемены
- **Рабочие дни** — звонки только в выбранные дни недели
- **Библиотека мелодий** — загрузка MP3/WAV, прослушивание, удаление
- **Автозапуск** — в production-версии приложение регистрируется в автозагрузке ОС (Windows / macOS)
- **Перезапуск в полночь** — планировщик автоматически пересчитывает события на новый день

Конфигурация хранится в `public/data/config.json` (dev) или `Resources/data/` (упакованное приложение).

## Экраны

Маршруты определены в `src/main.tsx`. UI-страницы лежат в `src/render/components/pages/`.

### Главная — `/`

**Файл:** `src/render/components/pages/main/main.tsx`

- Текущая дата и время
- Статус дня (рабочий / выходной)
- Активная или ближайшая смена
- Текущий урок / перемена с обратным отсчётом
- Следующий звонок
- Полное расписание на сегодня по всем сменам со статусами: прошёл / сейчас / предстоит

### Смены — `/streams/:id`

**Файл:** `src/render/components/pages/streams/streams.tsx`

- Редактирование расписания конкретной смены
- Добавление уроков и перемен
- Настройка времени начала, длительности и мелодии для каждой записи
- Drag-and-drop для изменения порядка (сохраняется автоматически)
- Предупреждение об окончании перемены (опционально)
- Кнопка «Сохранить настройки» — применяет расписание и перезапускает планировщик

Список смен отображается в боковом меню.

### Настройки — `/settings`

**Файл:** `src/render/components/pages/settings/settings.tsx`

- **Информация о школе** — название и адрес (отображаются на главной)
- **Расписание работы** — выбор рабочих дней недели
- **Настройки звука** — громкость, длительность звонка, режим «Без звука»
- **Библиотека мелодий** — загрузка, прослушивание и удаление звуковых файлов

### Справочник — `/reference`

**Файл:** `src/render/components/pages/reference/reference.tsx`

Встроенная инструкция по работе с программой: описание всех экранов, логики звонков и советы по эксплуатации.

## Важно при эксплуатации

- Программа должна быть **запущена** в момент звонка — планировщик работает внутри процесса Electron
- При выключении ПК все таймеры сбрасываются; при следующем запуске планировщик пересчитывает события от текущего времени
- В production-версии включён автозапуск при входе в систему
- Пропущенные звонки (если ПК включили после времени звонка) не воспроизводятся — это ожидаемое поведение
